# Hướng dẫn Build Tailwind CSS Tĩnh

1. Cài đặt Node.js trên máy tính của bạn.
2. Mở terminal tại thư mục này và chạy lệnh: `npm install`
3. Để build ra file CSS tĩnh (cho production): `npm run build:css`
4. Để vừa code vừa tự động build: `npm run watch:css`

File `style.css` sẽ được tự động tạo ra trong thư mục `assets/css/`.
